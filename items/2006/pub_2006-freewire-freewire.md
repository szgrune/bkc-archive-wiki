# FreeWire

**Source:** [cyber.harvard.edu](https://cyber.harvard.edu/publications/2006/FreeWire) · **Published:** 2006-11-15 · **Feed tags:** bkc-publication

> This application report reviews the FreeWire application, produced and distributed by FreeWireP2P.com.
> 
> We find that FreeWire is badware because it installs additional applications, including some with badware	behaviors, such as Trojan horses and adware, without the user's knowledge or consent. Some of these	bundled applications add icons to Internet Explorer, display pop-up ads, run at startup, and/or cannot be	easily closed.
