# UnSpyPC

**Source:** [cyber.harvard.edu](https://cyber.harvard.edu/publications/2006/UnSpyPC) · **Published:** 2006-05-22 · **Feed tags:** bkc-publication

> This application report reviews the UnSpyPC application, produced by "Stratex International" and distributed via www.unspypc.com.
> 
> We find that UnSpyPC is badware because it identifies legitimate anti-spyware applications as spyware and leaves	behind an executable after uninstallation that could be used to reinstall the program.
